# Flow Studio 产品需求与交互

## 用户流程

### FS-PR-01 双视图

项目顶栏提供 Canvas / Flow 切换，规范 URL 为
`/p/{projectId}?view=flow&workflow={workflowId}`。项目可包含多个 Workflow；切换视图不改变
Canvas 视口、选区和内容。两侧共享资产、对话、生成记录与凭据。

### FS-PR-02 创建与配置

Flow 为左侧节点库、中心 DAG、右侧检查器。用户从节点库增加节点，只能连接相同
`FlowValueType` 的端口；单输入端口不可重复连接，禁止环路。配置变更保存后递增
`graph_revision`，并将该节点及下游标记为过期，但不调用模型。

### FS-PR-03 显式运行

每个节点支持“运行此节点”“运行下游”，工具栏支持“运行全部”。强制重跑绕过选中节点及
下游缓存。运行固定到启动时修订；运行中的图编辑只影响下一次运行。

### FS-PR-04 运行状态

节点展示 pending、cached、queued、running、waiting_generation、waiting_user、succeeded、
failed、skipped、cancelled。人工选择节点进入 waiting_user，显示候选并等待用户决定。失败节点
可从该节点重试；取消不删除已有成功输出。

### FS-PR-05 输出与 Canvas

输出在 Flow 运行历史中预览和下载。只有“发布到画布”会创建 Canvas 节点；发布幂等，并保存
run、run node、output 血缘。新节点放在现有内容右侧，保持确定间距。

### FS-PR-06 模板和 Flow App

用户可把图发布为不可变个人模板版本。实例化复制图并重映射 UUID，不复制历史和缓存。Flow App
固定一个模板版本，以输入节点和作者允许暴露的配置路径生成表单。旧 App 版本不随模板升级漂移。

### FS-PR-07 Flow Agent

用户用自然语言请求调整工作流。Agent 只返回结构化 Patch；界面展示增加、更新、移动、删除的
差异。用户确认后服务端按 base revision 复核再应用。Agent 不运行图，不删除历史或资产。

## 节点目录

- 输入：文本、图片、视频、蒙版。
- 组织：Prompt 模板、图片集合、关键帧集合、图片选择。
- 图片：生成、语义编辑、局部重绘、扩图、移除背景、放大。
- 视频：视频生成、序列视频。
- 输出：文本、图片、视频、图库。
- 辅助：注释。

## 状态与错误

- 空图：展示推荐示例和节点库入口，不自动创建调用模型的节点。
- 模型不可用：节点阻断并要求明确选择替代模型，禁止 fallback。
- revision 冲突：保留本地修改，刷新服务端图后让用户重试确认操作。
- 离线：编辑进入 Outbox；运行、模板发布和 Agent 应用禁用。
- 部分失败：保留所有成功输出，运行标记 partial，可定点重试。
- 配置无效：检查器定位具体字段；图运行入口禁用。

## 验收

- 专业设计师可完成 FS-SC-01 至 FS-SC-05，无需进入 Canvas 才能调试 Flow。
- 相同修订重复运行不产生 Provider 调用；强制重跑行为可预测。
- 运行中的图编辑不改变固定修订，历史运行可完整追溯。
- 模板/App/Agent 均保持明确版本与用户确认边界。
