# v0.2.0 产品需求与交互设计

## 一、目标

让专业设计师在不离开设计页、不破坏原图片节点的前提下完成可控 AI 编辑。操作既可由精确画笔和几何控件驱动，也可通过提示词表达意图；结果必须先进入候选分支，由用户决定是否采用。

## 二、入口与布局

图片节点选中后的浮动工具栏新增「AI 编辑」。点击后，左侧画布区域进入专注编辑模式：保留设计页顶栏和右侧对话面板，以覆盖层承载图片预览和编辑控件。React Flow 实例保持挂载，当前视口、选择集与节点缓存不被重建。

编辑器顶部依次放置退出、操作切换、撤销、重做和蒙版显隐；中央为图片及编辑覆盖层；底部放置输入来源、模型、提示词、操作参数、候选数量和提交按钮。去背景不要求提示词，放大仅要求倍数，其余三种操作必须有非空提示词。

当某操作没有已配置且可用的模型时，操作入口仍可查看，但提交区域禁用，并显示「当前没有支持此操作的可用模型」及「配置模型」入口。模型不得在用户提交后才静默切换到另一操作。

## 三、五类操作

| 操作     | 输入与控件                                       | 输出与候选                                               |
| -------- | ------------------------------------------------ | -------------------------------------------------------- |
| 语义编辑 | 提示词、模型、输入保真度、1–4 个候选             | 修改整张图片语义，保留主节点位置和尺寸                   |
| 局部重绘 | 提示词、蒙版画笔、橡皮、大小、羽化、1–4 个候选   | 只允许模型修改蒙版白色及羽化区域，保留主节点几何         |
| 扩图     | 提示词、四边拖动、比例预设、自由尺寸、1–4 个候选 | 保持源图在新画布中的像素位置，采用时更新主节点比例和尺寸 |
| 去背景   | 模型、透明输出，一个候选                         | 产生透明 PNG，保持主节点几何                             |
| 高清放大 | 模型、2×/4×，一个候选                            | 提升自然像素尺寸，保持主节点视觉尺寸                     |

扩图比例预设为 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`。选择预设时以源图中心为锚点计算最小可容纳画布；自由模式允许分别拖动上、右、下、左边界，但不允许裁掉源图。输出尺寸受所选模型能力限制，超限时界面显示允许的最大值并禁止提交，不自动改变用户构图。

## 四、输入来源

### 使用原始资产

默认读取图片节点绑定资产的最高分辨率文件。节点在画布上的缩放、旋转、透明度和外框尺寸不改变提交像素；裁剪与滤镜也不烧录。该模式适合对源内容做最高质量编辑。

### 合并当前外观

用户主动开启后，系统渲染选中图片的当前裁剪和滤镜，并合成与其具有相同 `groupId` 的可见图片、文本、形状和手绘叠加节点。合成范围以选中图片裁剪后的内容框为基准，叠加节点按当前层级和相对位置裁切；不可见节点、生成占位、候选面板、画板外装饰和连线不参与。

节点旋转属于画布几何，不烧录进输入；图片节点透明度只影响画布呈现，不改变编辑源像素。合成结果作为辅助资产上传，后续重试始终复用同一资产，避免重试时画布变化导致输入漂移。

## 五、蒙版交互

- 画笔写入白色修改区域，橡皮擦恢复黑色保留区域。
- 画笔尺寸以源图片像素记录，界面根据当前预览比例换算显示。
- 羽化范围为 `0–128` 源像素，生成蒙版时把边缘写为灰阶 Alpha，不改变笔画中心。
- 每次连续按下、移动、抬起组成一条笔画；撤销和重做以整条笔画为单位。
- 「清空」作为一次可撤销操作；关闭蒙版显隐只影响预览，不改变数据。
- 提交前必须存在至少一个非黑像素；全黑蒙版以 `invalid_params` 拒绝。
- 快捷键为 `B` 画笔、`E` 橡皮、`[`/`]` 调整画笔、`Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 重做、`Enter` 提交、`Esc` 退出。

## 六、编辑状态机

```text
关闭 → 加载 → 编辑 → 准备输入 → 上传辅助资产 → 提交 → 等待结果 → 成功
                 ↘ 输入失败          ↘ 提交失败        ↘ 生成失败
任意未提交状态 → 取消 → 关闭
成功 → 返回画布查看候选 → 采用或保留候选
```

- **加载**：解析签名 URL、自然尺寸和节点外观；加载失败时允许重试或退出。
- **编辑**：全部参数和笔画仅存在本地会话，不写画布库或数据库。
- **准备输入**：生成合成图、蒙版和扩图描述；失败返回编辑态并保留参数。
- **上传辅助资产**：逐个上传并记录资产；失败清理本次未被 generation 引用的成功上传对象，再返回编辑态。
- **提交**：以幂等键原子创建 generation、输入引用与候选占位。
- **等待结果**：编辑器关闭，画布通过现有占位与 Realtime 展示状态。
- **成功/生成失败**：成功候选出现在主节点附近；失败占位提供使用原输入重试和移除操作。

## 七、候选与采用

提交任何编辑都不得立即修改目标图片。语义编辑、局部重绘、去背景和放大的候选沿用目标节点外框；扩图候选按新比例显示，并保持与目标节点相同中心点。

采用候选通过单一数据库事务完成：

- `preserve_frame`：主节点保留位置、宽、高和旋转，只交换资产与内容元数据；旧内容进入被采用候选原位置。
- `adopt_output_geometry`：扩图结果成为主内容，主节点中心点不变，宽高按输出比例在原面积基准上调整；旧内容及原几何进入候选分支。
- 主节点 ID 始终不变，以保护提及、边、会话上下文和外部引用。
- 多个候选没有自动优先级。用户可以采用任意一个、保留全部或逐个删除。

## 八、失败、空态与文案

| 场景                | 用户反馈                 | 恢复行为                         |
| ------------------- | ------------------------ | -------------------------------- |
| 无可用模型          | 显示操作要求与配置入口   | 保留编辑内容，配置后重新刷新能力 |
| 源图片加载失败      | 显示资源不可用及重试     | 续签 URL 后重载，不创建任务      |
| 输入超过模型上限    | 显示当前像素与模型上限   | 更换模型或调整扩图尺寸           |
| 辅助资产上传失败    | 标出失败阶段             | 保留笔画和参数，重新上传         |
| 提交失败            | 显示统一错误文案         | 使用相同幂等键安全重试           |
| Provider 失败或超时 | 候选占位显示失败原因摘要 | 复用原输入创建明确的新重试尝试   |
| 结果媒体无效        | 显示结果校验失败         | 原图不变，可切换模型重试         |
| 用户取消            | 若有未提交编辑则二次确认 | 确认后释放本地资源并返回画布     |

错误码与展示文案解耦。服务端继续使用现有小写错误码；图片编辑原因放入 `error.details.reason`，由中英文 i18n 映射显示。

## 九、无障碍与视觉规范

- 编辑器打开后焦点进入操作标题；关闭后返回触发它的「AI 编辑」按钮。
- 工具按钮具有可读名称、选中态和键盘焦点环；数值控件同时支持键盘输入。
- 透明图片和扩图空白使用明暗均可辨认的棋盘格；蒙版覆盖色不只依赖红绿色差异。
- 提交、上传和等待状态使用文本与进度指示，不只依赖动画。
- 中英文文案语义一致，Provider 名称和模型展示名不翻译。

## 十、验收

- 五类操作从同一图片节点入口可达，切换操作不会遗留不适用参数。
- 退出未提交编辑不会产生数据库、Storage 或画布写入。
- 输入准备和上传失败后，用户笔画、提示词、模型与扩图边界保持不变。
- 采用前原节点内容和几何不变；采用后主节点 ID 不变且候选交换符合对应几何策略。
- 无能力模型不会出现在选择器中，服务端也拒绝伪造的越权操作请求。
