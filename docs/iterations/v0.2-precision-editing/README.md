# NeoCanvas v0.2.0「精准编辑工作室」

## 一、版本定位

v0.2.0 面向专业设计师，把 NeoCanvas 从「在无限画布上生成和编排媒体」推进为「在同一画布中精确、非破坏地编辑既有图片」。本版本围绕图片节点提供语义编辑、蒙版局部重绘、扩图、去背景和高清放大五类能力，并复用既有生成事务、Realtime 回流和候选媒体机制，使编辑结果可比较、可采用、可回退。

版本按完整主题版交付，计划周期为 6–8 周。所有现有 Provider 都纳入统一能力体系，但界面只展示模型与适配器真实支持的操作；不支持蒙版的模型不会被包装成精准局部编辑模型。

## 五、统一术语

- **源资产（Source Asset）**：图片节点当前引用的、存储于自有 Storage 的最高分辨率媒体，是默认编辑输入。
- **辅助资产（Auxiliary Asset）**：为一次编辑生成的蒙版、降采样输入或「合并当前外观」图片。它参与审计与重试，但不出现在普通素材列表。
- **蒙版（Mask）**：与编辑输入具有相同像素坐标系的单通道透明度图；白色表示允许修改，黑色表示必须保留，灰色来自羽化边缘。
- **候选分支（Candidate Branch）**：与一个主媒体节点建立 `media_candidate` 关系的非破坏结果集合。生成候选不会改变主节点。
- **采用候选（Promote Candidate）**：在数据库事务内交换主节点和指定候选的内容；扩图还会按几何策略交换尺寸和位置。
- **操作能力（Image Operation Capability）**：一个模型在特定适配器协议下能够真实执行的图片操作。最终能力是适配器、模型目录和用户凭据的交集。
- **合并当前外观（Flattened Input）**：把选中图片的裁剪、滤镜以及同组可见叠加节点渲染为一张新输入图；节点旋转仍属于画布几何，不烧录进图片。

## 六、已锁定决策

- 目标用户是专业设计师，交互优先保证精度、可控性和可恢复性。
- 编辑器嵌入现有设计页左侧画布区域，不新增路由或常驻面板；右侧对话面板仍可使用。
- 默认编辑原始高分辨率资产，用户可主动切换「合并当前外观」。
- 所有编辑结果先成为候选，原节点不得被异步结果直接覆盖。
- 语义编辑、重绘和扩图可生成 1–4 个候选；去背景和放大固定生成一个结果。
- 所有 Provider 进入同一能力发现机制，但不允许静默降级、猜测请求 Schema 或虚报能力。
- 公开分享、版本历史、导出入口、品牌资产库、批处理、评论协作、时间线和 AI 文本排版不属于 v0.2.0。
