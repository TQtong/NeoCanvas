# 产品需求设计

## 一、目标用户与使用场景

本产品面向两类用户。第一类是没有专业设计技能、但有明确视觉表达诉求的「轻创作者」，例如运营人员需要一张活动海报、电商卖家需要一组商品主图、自媒体作者需要一段短视频开场。他们的核心诉求是「用一句话换一张能用的图」，对画布的期待是「能摆、能改、能导出」，而非精细的矢量编辑。第二类是「专业设计师与设计工作室」，他们把本产品当作灵感发散与初稿生成的加速器，先用模型快速铺出多个方向，再在画布上挑选、拼贴、二次生成，最后导出进入专业软件精修。两类用户共享同一套界面，差异只体现在使用深度上。

典型使用场景有四。其一是「从零起稿」：用户在主页输入想法、选模型，进入设计页后画布上直接出现首批生成结果。其二是「持续迭代」：用户在右侧对话中以「再换个配色」「把这只猫放大」「基于这张图生成视频」等指令，让画布内容逐步逼近预期。其三是「素材拼贴」：用户上传若干参考图与素材，配合形状、文本、手绘工具，在画布上手工组合，并以 `@` 提及把画布元素喂给模型做局部再生成。其四是「项目续作」：用户回到主页，从「最近项目」打开此前的画布，接续之前的对话继续创作。

## 二、功能总览

产品的功能版图由两个界面承载。主页是「创作的入口与作品的归档处」，承担发起创作（输入 + 选模型 + 建项目）与项目管理（最近项目浏览、新建、打开、续作）两组职能。设计页是「创作的发生地」，承担画布编辑（平移缩放、增删元素、变换排布、图层缩放控制）与智能体协作（对话、提及、附件、模型 / 模式选择、生成结果落画布）两组职能。两个界面之间通过「创建项目」与「打开项目」两个动作衔接，构成一条闭环：主页发起 → 设计页创作 → 主页归档 → 设计页续作。

贯穿两个界面的横切能力有三项：账户与会话（登录态、头像入口）、多模型能力（模型选择条与对话面板内的模型 / Agent 切换共用同一套模型目录）、以及作品资产（生成与上传的媒体统一沉淀为可复用的资产）。

## 三、主页结构与交互

主页在视觉上采用极简、强留白的布局，垂直方向自上而下分为三层，水平方向整体居中。

最上一层是产品标识与标语层。页面中部偏上居中展示产品 Logo 与「NeoCanvas 让设计更简单」字样，其下是一行浅灰色副标题「懂你的设计代理，帮你搞定一切」。这一层不承载交互，仅建立品牌认知与情绪基调。页面右上角固定一个信息簇：用户头像。头像点击展开账户菜单（含退出登录、设置入口）。

中间一层是创作输入层，是主页的功能重心。其核心是一个大号、圆角、带柔和边框的多行对话输入框，占位提示为「让 NeoCanvas 设计一张美丽的婚礼海报」，引导用户用自然语言描述需求。输入框左下角是一个「+」附件按钮，用于在发起创作时附带参考图；右下角是一枚立方体图标（代表 3D / 高级生成入口的占位）与一枚向上箭头的发送按钮，发送按钮在输入框为空时呈禁用态。输入框正下方是一条**模型选择条**：以图像、视频两个胶囊按钮切换本次创作的生成模态，并通过下拉菜单选择当前模态下的具体模型。所选模型的模态直接决定新会话的生成类型，不再叠加独立的场景选择。用户的选择会作为创建项目时的初始上下文，被带入设计页。

最下一层是「最近项目」层。区域以「最近项目」标题领起，下方是一个卡片网格。网格首位固定一张「新建项目」卡片，以虚线边框与居中「+」呈现，点击直接创建一个空白项目并进入设计页。其后按更新时间倒序排列历史项目卡片，每张卡片上半部是项目画布的缩略图（无缩略图时显示占位底色），下半部显示项目名（如「Untitled」）与更新时间（如「更新于 Jun 22, 2026」）。卡片点击进入对应项目的设计页；卡片悬停时浮现重命名、删除等次级操作。项目数量较多时，网格采用分页或滚动加载，每次增量拉取，避免一次性加载全部项目。

主页的核心交互流程是：用户在输入框写下想法（可选附参考图）→ 在选择条上确认生成模态与模型 → 点击发送 → 系统创建一个新项目、把这句想法落为该项目会话的首条用户消息、并立即跳转设计页 → 设计页加载后自动以该消息触发首次生成，用户进入设计页时即可看到生成正在进行或已经落到画布上。这一「输入即创建、创建即生成」的链路是产品「让设计更简单」承诺的第一兑现点。

## 四、设计页结构与交互

设计页是一个左右分栏的全屏工作台：左侧是占据绝大部分宽度的无限画布，右侧是一条可收起的对话面板。除这两个区域外，设计页不设任何其他常驻面板。

### 顶栏

顶栏横跨整个窗口宽度，左端是项目标识簇：产品小 Logo、项目名（如「Untitled」）、一个带下拉箭头的标签 / 版本切换控件（用于在同一项目的不同版本或标签间切换）。项目名支持双击就地重命名。顶栏右端复用主页的信息簇——用户头像——并额外提供对右侧对话面板的控制：展开 / 收起按钮（把对话面板折叠以让画布全屏）、分享按钮（生成项目分享链接）。对话面板自身的顶部另有一个「新对话」标题区，标题右侧重复提供新建对话、分享与收起的图标入口。

### 无限画布（左侧）

画布是一块可向任意方向无限平移、可在合理倍率区间内无级缩放的二维平面。空画布在中心显示引导语「输入你的想法开始创作，或按 C 开始对话」，提示用户既可以直接在画布上操作，也可以用快捷键 C 把焦点切到右侧对话。画布支持的基础视口操作包括：滚轮 / 触控板缩放、按住空格或中键拖拽平移、双指平移与缩放、框选多个元素、点选单个元素并显示其变换手柄。

画布底部居中悬浮一条**工具栏**，从左到右依次是十个工具，每个工具对应一种画布操作模式或一次元素创建动作：

| 工具                     | 名称        | 作用                                                        |
| ------------------------ | ----------- | ----------------------------------------------------------- |
| 箭头                     | 选择 / 移动 | 默认模式，用于选中、拖动、变换已有元素与平移画布            |
| 定位针                   | 抓手 / 定位 | 切换为纯平移抓手模式，便于在大画布上快速移动视口            |
| 图片（带上箭头）         | 上传图片    | 从本地选择图片文件，上传后作为图片元素落到画布              |
| 井号网格                 | 画板 / 网格 | 创建一个固定尺寸的画板框（frame），并切换画布背景网格的显隐 |
| 矩形                     | 形状        | 进入形状绘制模式，拖拽即在画布上绘制矩形（及其扩展形状）    |
| 画笔                     | 手绘        | 进入自由手绘模式，按住拖动留下笔迹路径                      |
| 字母 T                   | 文本        | 进入文本模式，点击画布落点即创建可编辑文本框                |
| 图片（带星）             | AI 图像     | 调起 AI 图像生成，在指定位置落生成结果                      |
| 播放（带星）             | AI 视频     | 调起 AI 视频生成，落视频元素                                |
| 字母 T（带星，带提示点） | AI 文本     | 调起 AI 文案 / 图文生成                                     |

画布左下角是一个轻量控件簇：一枚圆形图标（用于切换某种视图模式 / 评论模式的占位）、一枚图层堆叠图标（展开当前画布元素的层级列表，用于调整前后顺序）、一枚带放大镜的图标（定位 / 聚焦元素）、一枚视图工具图标，以及当前缩放比例显示（如「100%」），缩放比例可点击展开预设倍率与「适应画布」。这些控件刻意保持精简，不构成完整的图层树编辑器。

每个画布元素被选中后，其四周出现缩放手柄（用于改变尺寸），上方浮现一条与元素类型相关的浮动工具条（例如图片元素提供「以此为参考再生成」「替换」「删除」「置顶 / 置底」，文本元素提供字体、字号、颜色、对齐）。多个元素被框选时作为一个临时组进行整体移动与缩放。元素的前后层级通过图层控件或浮动工具条调整。

### 对话面板（右侧）

对话面板是用户指挥智能体的主通道。面板顶部是「新对话」标题区与其控制图标。主体区在无消息时居中显示大标题「What do you want to create?」，营造开放式邀请；有消息后则自上而下呈现对话流，用户消息靠一侧、智能体回复靠另一侧，智能体在执行生成时以可视的进行态（进度、缩略预览）呈现，并在完成后把结果同步落到左侧画布对应位置。

面板底部是对话输入区，占位提示为「Start with an idea, or type "@" to mention」。输入区支持三类增强：其一，键入 `@` 触发提及选择器，列出当前画布上的元素（按类型与缩略图区分），被提及的元素将作为上下文 / 参考图随消息一并提交给模型，用于「针对画布上某个具体元素再生成 / 编辑」；其二，输入区左下角的「+」按钮用于上传附件（参考图、素材）；其三，输入区内含一个「Agent」模式下拉，用于在不同的工作模式（如纯生成、编排式智能体、特定场景流程）间切换，并隐含当前所用的生成模型。输入区右下角是发送按钮与一枚高级入口图标。发送后，消息进入会话流并触发相应的生成或编排。

### 设计页核心交互流程

设计页的主循环是「对话 → 生成 → 落画布 → 在画布上调整 → 再对话」。一次典型循环为：用户在右侧输入指令（可 `@` 提及画布元素、可附图）→ 系统创建生成任务 → 对话流出现进行态、画布上对应位置出现一个生成占位元素 → 模型产出结果后，占位元素原地替换为真实的图片 / 视频元素，对话流标记完成 → 用户在画布上拖动、缩放、排布该元素，或选中它在浮动工具条上发起「以此再生成」→ 进入下一轮。整个过程中，画布与对话双向联动：画布上的选择可被提及进对话，对话产出的结果实时落进画布。

## 五、端到端核心用户旅程

把两个界面串起来，产品的主旅程是一条从「想法」到「成品」的连续线。用户登录后落在主页，写下一句想法并选定模型，点击发送；系统创建项目、记录首条消息并跳转设计页；设计页加载画布与会话，自动触发首次生成，首批结果落到画布中央；用户审视结果，在对话中继续追加指令做多轮迭代，期间穿插使用画布工具上传素材、添加文本、调整排布；当画布达到预期，用户通过项目菜单导出成品（图片 / 视频 / 画布快照）；离开时项目自动保存，缩略图与更新时间回写；日后用户从主页「最近项目」重新进入，接续既有对话与画布继续创作。这条线上，每一步的产出都被持久化，每一次进入都能无缝续作，这是产品「连续创作」体验的根基。

## 六、交互细节与快捷键

画布交互需达到专业工具的手感。平移、缩放须跟手且有惯性与边界阻尼；框选须支持加选与减选；元素拖动须有对齐参考线与吸附；缩放手柄须支持等比与自由两种模式；删除、复制、粘贴、撤销、重做须齐备。键盘快捷键至少覆盖：C 聚焦对话、V 选择工具、H 抓手、R 矩形、T 文本、P 画笔、Delete 删除选中、Cmd/Ctrl+Z 撤销、Cmd/Ctrl+Shift+Z 重做、Cmd/Ctrl+C/V 复制粘贴、空格临时抓手、缩放快捷键与「适应画布」。对话输入须支持 Enter 发送、Shift+Enter 换行、`@` 唤起提及。所有破坏性操作（删除元素、删除项目）须可撤销或有二次确认。

## 七、视觉设计语言

产品视觉以「克制的现代感」为基调，服务于「让创作本身成为主角」。界面同时提供亮色、暗色与跟随系统三种主题偏好：亮色采用大面积浅色留白，暗色使用低亮度中性色背景与清晰的层级对比；偏好在本机持久化并于首屏绘制前恢复，避免页面闪烁。前景元素以高对比文字与细描边卡片呈现，强调内容而弱化装饰。圆角统一偏大，营造柔和、友好的观感；阴影轻薄、扩散柔和，用于建立层级而非堆叠厚重。强调色采用一抹克制的紫色，仅用于当前选中的模型、主操作按钮等少数焦点，避免色彩泛滥。

界面中的悬浮元素——画布底部工具栏、对话输入框、浮动工具条、各类弹层——采用半透明磨砂玻璃（frosted glass）质感，背景虚化、边缘高光、微妙投影，使其既漂浮于画布之上又不割裂画面。字体在中英文混排下保持一致的字重与行高节奏，技术性标签（模型名、Agent、英文引导语）保留英文原文，正文与功能性文案以简体中文为主，体现产品中英混排的真实语境。动效追求「轻、快、有反馈」：视口缩放平滑，元素出现与替换有短促的淡入与缩放过渡，生成进行态有持续而不刺眼的动态指示。

## 八、非功能性需求

性能上，画布须在数百至上千个元素规模下仍保持流畅的平移与缩放（依赖仅渲染可视区域、节点记忆化等手段）；首次生成结果应尽快可见，异步生成须有清晰的进度反馈而非空等；主页项目列表须分页加载，避免随项目增长而变慢。可靠性上，画布状态须持续、增量地持久化，断网恢复后不丢失编辑；生成失败须可重试。安全与隐私上，用户只能访问自己的项目与资产，外部模型密钥不得下发到客户端，分享链接须可控可撤销。可用性上，关键操作有加载态、空态与错误态三套反馈；破坏性操作可撤销。国际化上，界面在简体中文与英文之间可切换，并尊重界面草图中既有的中英混排现状。可达性上，工具与按钮提供可读的可访问名称，主要操作支持键盘完成。

## 九、精准图片编辑（v0.2.0 当前能力）

带有效源资产的图片节点在浮动工具条提供「AI 精准编辑」入口。入口打开画布内模态工作室，React Flow 画布、视口与右侧对话保持挂载，但画布选择、拖拽、缩放和快捷键在编辑期间锁定；取消或提交后恢复原视口与入口焦点。生产构建只有在 `NEXT_PUBLIC_IMAGE_EDITING_ENABLED=true` 时展示入口，关闭开关不会改变既有任务、资产和数据库结构。

工作室提供五类操作：语义编辑根据提示词改变整图语义；局部重绘只修改用户在源像素坐标中绘制的蒙版区域；扩图支持四边自由外扩及 1:1、4:3、3:4、16:9、9:16、3:2、2:3 比例；去背景固定输出带透明通道的一个候选；高清放大支持模型真实声明的 2×/4× 倍率。操作页签只显示当前凭据、模型目录和 Adapter 协议共同支持的模型，像素级重绘不得由语义编辑能力替代。

默认输入为图片节点当前引用的原始高分辨率源资产。用户可切换「合并当前外观」，把裁剪、滤镜及与图片同组且相交的可见文字、形状和手绘叠加渲染为辅助输入；图片节点旋转、外框透明度和圆角继续作为画布几何与外观保存，不烧录到编辑输入。切换输入或模型时会重新按模型最大像素数等比约束输入，准备期间明确显示状态并禁止重复提交。

蒙版工具提供画笔、橡皮、画笔大小、0–128px 羽化、显隐、清空、撤销和重做。蒙版与源图片像素一一对应，不随预览缩放、设备像素比或画布视口变化；键盘可用 B/E 切换工具、空格在中心绘制、Ctrl/Cmd+Z 与 Ctrl/Cmd+Shift+Z 撤销重做。透明图片与去背景结果统一使用棋盘格呈现透明区域。

所有结果先进入目标节点右侧的候选分支，生成完成前原节点不变。语义编辑、局部重绘、扩图支持 1–4 个候选，去背景和放大固定一个。采用语义编辑、重绘、去背景或放大候选时保留主节点外框与位置，放大只更新资产自然尺寸；采用扩图候选时保持主节点中心不变并采用输出比例。采用操作在事务内交换主节点与候选内容，旧主内容回到候选节点，因此任何成功结果都可逆。

编辑会话覆盖准备输入、上传、提交、等待、失败、取消等状态。无可用模型时显示 Provider 配置入口；输入拉取、合成、上传或生成失败时保留提示词、蒙版和参数以便重试；目标节点被 Realtime 更新时继续使用打开工作室时冻结的输入并给出提示，被删除时保留预览但禁用提交。关闭未提交的脏会话需要确认，取消会中止在途浏览器任务并清理尚未被 generation 引用的辅助资产。

该能力的验收基线是：五类操作均可从图片节点进入并走完候选闭环；原节点在提交与失败期间不被覆盖；蒙版、扩图几何、自然尺寸和透明通道符合操作语义；模型选择器不展示虚报能力；上传失败、Provider 失败、Realtime 更新/删除和键盘路径均有确定的恢复行为。
